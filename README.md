This project involves performing a complete exploratory data analysis (EDA) on the famous Iris dataset. 
The goal is to understand the structure of the data, uncover relationships between variables, visualize key trends, and derive meaningful insights that could later be used in predictive modeling or machine learning tasks.
🧠 Motivation
Understanding data is a fundamental step before building any machine learning model. This project serves as a solid EDA foundation that highlights:

The importance of visualizing data.

How feature relationships impact classification.

Why data cleaning and exploration come before modeling.
